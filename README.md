# MX.DEV — Portfolio Website

Personal portfolio website showcasing frontend development work, built with a focus on smooth animations and performance.

## 🚀 Features

- Custom cursor effects
- GSAP-powered scroll and timeline animations
- WebP image optimization for fast load times
- FOUC (Flash of Unstyled Content) fixes
- Downloadable CV/Resume

## 🛠️ Tech Stack

- HTML5
- CSS3
- JavaScript
- [GSAP](https://gsap.com/) (GreenSock Animation Platform)

## 📦 Setup

Install dependencies and build the stylesheet:

```bash
npm install
npm run build
```

The source stylesheet is `src/input.css`; the generated stylesheet is `css/tailwind.css`. Run `npm run dev` while editing to rebuild it automatically. Open `index.html` in your browser, or use a local server (e.g. VS Code Live Server) for best results with asset loading.
